# 档案装裱排版校验台

在 1000×700 毫米卡纸上安排观察窗，提交后由裁决引擎判断方案
**可裁切 / 不可裁切**，并高亮全部冲突（开窗侵入内置瑕疵区、开窗彼此正面积相交、
越过压边安全区等）。合法方案与完整裁决结果落 PostgreSQL，刷新/重启后恢复同一布局。

- **Web**：React + Vite，支持在纸面上**拖放开窗**、拖动移位、填写 x/y/宽/高
  （圆形窗为 x/y/直径），可在**矩形窗与圆形窗**之间切换，并可选择
  **1 / 5 / 10 毫米定位步长**，三种编辑方式按同一规则即时吸附
- **API**：FastAPI + SQLAlchemy，逐字段校验、整批事务落库
- **DB**：PostgreSQL 16
- 前端（Vitest + Testing Library）与后端（pytest）均有测试

## 坐标约定（务必先读）

- 纸张固定 **1000 × 700 毫米**，**左上角为原点**，x 轴向右、y 轴向下。
- 开窗坐标与尺寸必须为**整数**；宽、高**至少为 1**。
- **开窗形状**（`shape`，可选）：
  - `rect`（缺省）：矩形窗，半开矩形 `[x, x+w) × [y, y+h)`。
    旧请求与旧记录缺少 `shape` 时一律按矩形读取。
  - `circle`：圆形窗，以 `(x, y)` 为外接矩形左上角，**宽高必须相等**，
    即直径 `w == h`；圆心 `(x+w/2, y+h/2)`、半径 `w/2`
    （直径为奇数时圆心/半径落在半整数坐标上）。
  - 页面上可把当前观察窗在矩形与圆形之间切换：转圆形时以当前
    **宽高中较小值作为直径**并按所选步长吸附；其余矩形窗的操作与
    结论保持原样。画布对圆形窗绘制**真实圆轮廓**，表单改用**直径**输入。
- **压边安全区**：可用内区满足
  `12 ≤ x`、`x+w ≤ 988`、`12 ≤ y`、`y+h ≤ 688`（圆形按外接框判定）。
- **定位步长**：页面可选 1、5 或 10 毫米步长。吸附以**安全内区左上角 (12,12) 为基准**：
  位置与尺寸取最近合法刻度，恰好居中时取较小值；靠近右侧或下侧时回退到
  最后一个容得下整窗的刻度。拖放、移动、表单编辑共用同一条规则。
  步长随布局一起提交保存，刷新后恢复同一选择。
- **半开矩形**：矩形开窗与瑕疵区均为 `[x, x+w) × [y, y+h)`。
  只有**正面积相交**才算冲突；**边线相接、角点相接允许**。
  - 例如开窗左边线正好贴瑕疵区右边线（两个区间端点相同）不冲突；互相侵入 1 毫米即冲突。
- **圆形相交**：圆与矩形瑕疵/矩形开窗按“圆心到矩形闭区域最近点距离 < 半径”，
  圆与圆按“圆心距 < 半径和”；同样只有**正面积相交**才算冲突，
  **边线相切、角部外切、两圆外切均允许**，互相侵入 1 毫米即冲突。
  引擎在**整数放大坐标**（几何量整体乘 2）上精确比较平方距离，
  半整数圆心/半径也无浮点误差。
- **内置只读瑕疵区**（裁决引擎内置，不随方案保存，页面上没有任何录入/编辑入口）：
  - `[200,280) × [150,190)`
  - `[620,680) × [420,510)`
- 开窗之间使用同一条半开矩形正面积相交规则。

## 启动（Docker Compose）

应用组件只有 **web** 与 **api** 两个；`db` 是 PostgreSQL 支撑服务。

```bash
docker compose up --build
```

- 前端（Web）：http://localhost:8080
- 后端（API）：http://localhost:8000  （Swagger 文档：/docs）

宿主端口可用环境变量覆盖：

```bash
WEB_PORT=9090 API_PORT=9000 docker compose up --build
# 或写入 .env（见 .env.example）
```

## 一次性验收服务

`verify` 是跑完即退的一次性服务，对运行中的真实容器栈打 HTTP 请求，
覆盖：健康检查、内置瑕疵区、逐字段 422 错误且整次不落库、合法落库、
刷新恢复、半开矩形边界、双方冲突高亮、安全区边界、工件编号、
定位步长（保存/恢复、偏离刻度 422、旧格式按 1 毫米）、
圆形观察窗（矩形切换圆形的确定尺寸、圆与瑕疵/圆/矩形开窗的外切与
侵入 1 毫米、非法形状与宽高不等 422、混合形状刷新一致）、
web → /api 反代接线。

```bash
docker compose up --build -d
docker compose run --rm verify
```

全部断言通过时退出码为 0。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| GET | `/api/defects` | 内置只读瑕疵区与纸张/边距常量（仅用于绘制） |
| GET | `/api/layout` | 读取最近一次合法提交（开窗 + 完整裁决）；无提交时为空布局 |
| PUT | `/api/layout` | 整批提交并裁决 |

提交体：

```json
{
  "step": 5,
  "windows": [
    {"shape": "rect", "x": 302, "y": 302, "w": 105, "h": 60, "label": "ZW-2026-001"},
    {"shape": "circle", "x": 307, "y": 312, "w": 65, "h": 65}
  ]
}
```

- `shape`（可选）：开窗形状，`rect`（矩形）或 `circle`（圆形）；
  未携带或 `null` 一律按 **rect** 处理（旧客户端与旧记录兼容）。
  非法值（如 `"ellipse"`、数字、布尔等）→ **422**，按行返回
  字段名为 `shape` 的错误。
  圆形窗**要求宽高相等**（均为直径），宽高不等 → **422**，
  按行同时返回 `w`、`h` 两个字段错误。两类错误都**不写入布局**。
- `step`（可选）：定位步长，只接受 **1、5、10**（毫米）；未携带或 `null` 一律按 **1** 处理
  （旧客户端与旧记录兼容）。携带步长时，每扇开窗的坐标与尺寸都必须落在对应刻度上
  （圆形直径同样要符合刻度，基准为安全内区左上角），否则按行返回字段错误。
- `label`（可选）：工件编号（藏品登记号），用于画布、列表与冲突说明中识别每扇窗；
  未携带、`null` 或全空格一律按空值处理（页面显示原有顺序号 `#1`、`#2`…）。
- 编号按**去除首尾空格后**的文本校验：**长度 ≤ 24 字符**且**同一布局内不重复**；
  合法值（去空格后）随开窗与完整裁决一起保存，刷新后原样恢复。
- 任一字段非法（非 JSON 整数、宽高 < 1、越过安全区、偏离步长刻度、缺字段、
  非法形状、圆形宽高不等、编号超长/重复、step 不是 1/5/10 等）→ **422**，
  响应按开窗行号给出**逐字段错误**（编号错误的字段名为 `label`），且**整次提交不落库**。
- 合法（即使裁决为“不可裁切”）→ **200**，保存步长、全部开窗（含形状）与完整裁决：

```json
{
  "verdict": "不可裁切",
  "step": 5,
  "windows": [
    {"id": 11, "position": 0, "shape": "circle", "x": 307, "y": 312, "w": 65, "h": 65, "label": null}
  ],
  "result": {
    "verdict": "不可裁切",
    "defect_conflicts": [{"window_id": 11, "defect_index": 0}],
    "window_conflicts": [],
    "conflicting_window_ids": [11]
  }
}
```

页面始终只展示唯一结论：**可裁切** 或 **不可裁切**；
`conflicting_window_ids` 中的开窗与被命中的瑕疵区全部高亮，
冲突说明逐条以编号（未填写时为顺序号）指认涉及的开窗。

## 目录结构

```
.
├── docker-compose.yml      # web / api 两个应用 + db + 一次性 verify
├── verify/verify.py        # 端到端验收脚本（纯标准库）
├── backend/                # FastAPI + SQLAlchemy
│   ├── app/engine.py       # 裁决引擎（半开矩形、圆形整数放大坐标、逐字段校验、瑕疵区常量、步长刻度）
│   ├── app/validation.py   # 原始 JSON 整数校验（拒绝 3.5 / "5" / true）、形状/编号与步长校验
│   ├── app/migrate.py      # 启动时的幂等轻量迁移（为旧库补 windows.label/windows.shape / layouts.step 可空列）
│   └── tests/              # pytest
└── frontend/               # React + Vite
    ├── src/geometry.js     # 与引擎同构的前端镜像（即时预览、圆形几何与步长吸附，后端为准）
    └── src/__tests__/      # Vitest
```
